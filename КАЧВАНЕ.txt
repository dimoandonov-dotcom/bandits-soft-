КАЧВАНЕ НА bandits-soft-
=========================

Тази папка Е ВЕЧЕ готово git хранилище с два commit-а.
Разархивирай я, отвори команден ред ВЪТРЕ в нея и изпълни два реда:

  git remote add origin https://github.com/dimoandonov-dotcom/bandits-soft-.git
  git push -u origin main

При push:
  потребител: dimoandonov-dotcom
  парола:     токенът github_pat_... (НЕ паролата на GitHub)

Ако git каже, че папката не е хранилище, значи архивът е разархивиран без
скритите файлове (.git) - разархивирай пак с показани скрити файлове.

Ако нямаш git: https://git-scm.com/download/win
