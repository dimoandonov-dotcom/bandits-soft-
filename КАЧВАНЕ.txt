КАЧВАНЕ НА bandits-soft-
=========================

Тази папка Е ВЕЧЕ готово git хранилище с два commit-а. Разархивирай я,
отвори команден ред ВЪТРЕ в нея и изпълни само два реда:

  git remote add origin https://github.com/dimoandonov-dotcom/bandits-soft-.git
  git push -u origin main

При push:
  потребител: dimoandonov-dotcom
  парола:     токенът github_pat_... (НЕ паролата на GitHub)

Ако git не вижда папката като хранилище (липсва .git), значи архивът е
разархивиран без скритите файлове - разархивирай пак с показани скрити файлове.

Ако нямаш git: https://git-scm.com/download/win
