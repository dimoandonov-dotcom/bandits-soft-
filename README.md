# bandits-soft

Апито за документооборота на Бандитс ООД. Истината са Google Sheets;
Mongo е огледало, от което се чете бързо.

## Защо е хранилище, а не „функция"

До 20.10.2026 услугата беше Railway „функция" — **един файл** с твърд таван
**98 304 байта**. На 20.10 кодът беше 97 302 байта, тоест оставаха 1002.
Опасното е как се проваля: мине ли файлът тавана, Railway не отказва —
инструментът връща `changed: true`, а живата услуга си върти стария код.
Случи се веднъж. Затова всяко качване се доказва с `md5` и `cmp` срещу живия код.

## Модулите

| Модул | Какво държи |
|---|---|
| `config.ts` | SHEET_ID, MASTER_URL, имена на листове, серии, ключове на таблиците |
| `db.ts` | връзката към Mongo, `db()`, режимът („огледало" / „стопанин") |
| `util.ts` | CSV, дати, числа, нормализиране на обекти и номера |
| `sync.ts` | четене на листовете и опресняване в Mongo |
| `numbers.ts` | броячите и заделянето на номера (`seedCounters`, `reserveNums`) |
| `mirror.ts` | опашката към листовете (`mirrorQueue`, `flushMirror`) |
| `gas.ts` | Apps Script — `gasCall`, `gasReserve`, `writeThroughSheets`, сверки |
| `sources.ts` | заявки-източници, ВЕГА кодове, защита от двойно пускане |
| `issue.ts` | дневното издаване (`issueDocs`) — стокови и фактури |
| `manual.ts` | ръчна продажба и ръчно КИ/ДИ |
| `credits.ts` | масовите КИ по връщания |
| `deliveries.ts` | доставки — фактури и КИ, поправки по редове |
| `stokovi.ts` | връзване на стокови разписки към фактура |
| `sheetops.ts` | добавяне и промяна на редове в листовете |
| `reports.ts` | `/health` и `/check` — дневните проверки |
